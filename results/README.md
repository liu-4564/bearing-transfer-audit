# Result files

436 JSON files, one per configuration, plus `tables.md`. Two more files are bookkeeping
rather than results: `summary.json` (the index `src.summarize` walks) and
`rig_distances.json` (the cached descriptor distances, so Fig. S1c and Table 4 rebuild
without the raw corpora).

Every file is a flat record. The fields that matter:

| Field | Meaning |
|---|---|
| `model` | `xgb`, `cnn`, `resnet` |
| `src`, `tgt` | source and target dataset; `null` for within-dataset runs |
| `split` | `random` (windows shuffled) or `run` (whole runs held out) |
| `norm` | `window` (per-window z-score) or `global` (corpus-wide statistics) |
| `k` | target samples per class used for calibration; `0` = none |
| `snr` | `null` for clean runs, otherwise the test-set SNR in dB |
| `seed` | random seed |
| `bacc` | balanced accuracy on the held-out target split |
| `f1`, `kappa` | macro F1 and Cohen's κ |
| `confusion` | 3×3 matrix, rows = true, order `[healthy, inner, outer]` |

`bacc` is the number quoted everywhere in the paper. It is used instead of
plain accuracy because the three classes are not equally frequent in CWRU and
MFPT.

## File naming

```
{protocol}_{src}2{tgt}_{model}_{norm}[_k{K}][_snr{S}][_s{SEED}].json
```

- `protocol` is `random` or `run` for within-dataset runs, `cross` for transfer.
- `_k{K}` is present only when `K > 0`; absent means `k = 0`.
- `_snr{S}` is present only for noise-sweep runs; absent means clean.
- `_s{SEED}` is present only for the few-seed sweeps; absent means `seed = 42`.

Examples:

```
run_mfpt_xgb_global.json              MFPT, whole-run split, global norm, k=0, clean, seed 42
cross_cwru2pu_resnet_window_k20_s7.json   CWRU→PU, 20 samples/class, seed 7
cross_pu2cwru_cnn_global_snr0.json    CWRU←PU at 0 dB — noise sweep, NOT a clean baseline
```

## Two traps

**`_snr` files are not clean baselines.** They carry `k = 0` in their config
because the cross-dataset protocol always has `k = 0` when no calibration data
is given, so filtering on `k == 0` alone will sweep them in. Filter on
`snr is None` as well.

**Do not average all runs flat.** The three model families have different seed
counts. Average within a family first, then across families — see
`model_family_means` in `src/make_figures.py`.

Both traps are documented at greater length in `../REPRODUCING.md`.

## tables.md

Regenerated by `python -m src.summarize`. Tables 1–3 are per-model; Table 4 is
the family-equal-weight cross-dataset summary together with the two
correlations against descriptor-space rig distance. It is the only file here
that is derived rather than raw.

The numbers here predate the typesetting. The four tables in this file appear in
the paper as Table S1 (here Table 1), Table S2 (here Table 2), Table S3 (here
Table 3) and Table 1 of the main text (here Table 4).

## rig_distances.json

The three pairwise distances of §2.5 are not a result of any single run: they
are computed from the waveforms. The values are cached here so that
`src.summarize` and `src.make_figures` can rebuild Table 1 and Fig. S1c from a
checkout that has no corpora. The cache is only read when the corpora are
absent, so regenerating with the data present always overwrites it.
